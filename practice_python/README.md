Small drills and bigger challenges for every core topic. Levels: 🟢 easy, 🟡 medium, 🔴 hard. 
Work in order within each topic, type everything yourself, and run it after every few lines. 
When stuck, re-read the error message first, then your cheat sheet.

How to use this bank:
1. Make a folder python_practice/ with one file per topic (01_variables.py, 02_strings.py, and so on).
2. Put each exercise in a function or a clearly marked block with a comment of the exercise number.
3. Predict the output before you run the code. If it differs, figure out why.
4. Do the 🔴 ones last, and without looking anything up for the first 10 minutes.
